## Почему этот инструмент (Трек C: Sass + BEM)
Я выбрал методологию BEM, так как она делает структуру стилей предсказуемой и защищает от конфликтов классов. Разделение на `block__element--modifier` позволяет легко читать код и понимать, к какому компоненту относится стиль. Препроцессор Sass отлично дополняет BEM: благодаря вложенности (nesting) код становится компактнее и логичнее. Переменные позволяют в одном месте управлять всей цветовой палитрой и шрифтами проекта. Использование миксинов (таких как `@mixin respond-to`) делает написание адаптива прямо внутри блоков очень удобным. В отличие от фреймворков вроде Bootstrap или Tailwind, этот подход оставляет HTML-разметку чистой, без нагромождения десятков утилитарных классов, сохраняя полный контроль над дизайном.

*Примечание: При генерации структуры BEM, написании SCSS-миксинов и оформлении README использовался ИИ (Gemini).*
